Introduction: Responsibilities of an Operating System (OS)

1. Process Management
2. Schedules and runs programs
3. To communicate the instructions
4. It blocks risky and bad access passwords, logs and checks from the user
5. It manages memory
6. It provides ways for users to interact with computers
7. It track and assigns RAM to activate apps.

The fundamental difference between physical Hardware and software instructions:

 - Hardware focuses on the touchable parts of the computer e.g Mouse, motherboard, keyboard etc
 - Hardware is tangible (you can touch it)
 - Software is intangible (you cannot touch it)

 5 Internal hardware components:

 1. Central Processing Unit (CPU)
 2. Random Access Memory (RAM)
 3. Motherboard
 4. Storage Drive
 5. Hard disk drive
